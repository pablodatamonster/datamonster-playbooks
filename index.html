Playbooks for the datafam

Set it up once, write it down, share it

Step-by-step guides for the platforms and tools I set up on client projects. Each one is written for someone doing it for the first time, explains the reason behind every step and keeps a learning log of what tripped me up.

Library

How each playbook is laid out

  1. What and when
  2. Before you start, permanent choices flagged
  3. Big picture diagram
  4. Steps, with the reason behind each
  5. Gotchas
  6. Checklist for next time
  7. Used on
  8. Learning log, newest first

Names such as CLIENT_PILOT and ITADMIN are placeholders. No details from real client projects are published. Screens and prices change: check the "Last checked" date and the vendor's current documentation.
